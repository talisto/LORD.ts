# Barak's House

**An interactive IGM for Legend of the Red Dragon**

## Overview

Barak's House lets players visit Barak and his crazy mother for humorous encounters, arcade mini-games, and powerups. The IGM can only be entered once per day and features multinode compatibility, automatic maintenance, and carrier loss handling.

### Features

- One-time-per-day entry limit
- Humorous character encounters and antics
- Three possible arcade mini-game sequences
- Various stat rewards and powerups
- Seamless LORD integration: "looks and feels exactly like LORD"
- Multinode compatible with automatic daily reset
