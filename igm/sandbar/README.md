# Sandtiger's Bar

**A commerce and gambling IGM for Legend of the Red Dragon**

## Overview

Sandtiger's Bar is a full-featured commerce and entertainment module for LORD featuring a custom currency system, gambling games, a black market, NPC interactions, and player-cursing mechanics.

### Features

- **BarCoin Currency**: Gold is exchanged for BarCoins on entry and converted back on exit
- **Gambling Table**: Three games: Blackjack, Elimination, and Five Card Draw
- **Black Market**: Buy and upgrade stats (HP, STR, DEF, CHA), weapons, armor, skills, forest specialties, class changes, and protection spells
- **NPC Characters:**
  - Sandtiger (bartender with flavor text)
  - Old Witch (curse other players for BarCoins)
  - Turgon (money exchange NPC)
- **Configurable Pricing**: Uses level-based formula system for balanced economy
- **Multinode Support**: Full compatibility with simultaneous LORD gameplay
