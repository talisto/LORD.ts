# Seth's Lotto

**A lottery IGM for Legend of the Red Dragon**

## Overview

Seth's Lotto is a once-per-day lottery IGM where players buy a ticket and enter a 4-digit code, hoping to match the randomly generated winning numbers. Prizes scale with player level and the number of digits matched. The IGM has minimal impact on the overall LORD economy.

### How It Works

1. Buy one lottery ticket per day (cost: 10 × player level in gold)
2. Enter a 4-digit code (digits 0–9)
3. The machine generates 4 random digits
4. Win prizes based on how many digits match (order-independent)
5. Prize amounts scale with player level
