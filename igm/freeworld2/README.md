# FreeWorld II

**A once-per-day adventure IGM for Legend of the Red Dragon**

## Overview

FreeWorld II is a once-per-day adventure IGM where players explore a magical world, encountering random events along forest walks, visiting the High Chancellor for a gold-prize guessing game, and discovering the Wishing Well for stat upgrades.

### Features

- **10 Random Walk Events**: Including fairy healing, pit traps, mysterious figures, ancient ruins, treasure pouches, and more
- **High Chancellor's Game**: Guess a number 1–100 in 5 tries for 50,000 gold
- **Wishing Well**: Choose from 13 different stat upgrades with randomized amounts
- **Full Stats Screen**: View all player statistics
- **Old Man Encounter**: Flavor interactions with attack/question/leave options
- **Daily Limit**: Can only be played once per day

## Porting Information

This TypeScript version was ported from the original Virtual Pascal source. The four identical "path goes forever" no-op walk events from the original were replaced with four distinct flavor events. All other game logic is faithful to the original.
